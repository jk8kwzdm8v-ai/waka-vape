# Waka Vape — готовая страничка

Сайт сделан как информационный каталог WAKA soPro PA10000 в сине-голубой/чёрно-белой стилистике.

## Что уже есть
- адаптивная версия для телефона и ПК;
- меню «три полоски» слева;
- разделы «О нас» и «Каталог»;
- русский / ქართული / English;
- переключение языка без перезагрузки;
- 18 вкусов;
- карточка каждого вкуса открывает подробное окно;
- возрастное подтверждение;
- блок характеристик;
- места для ваших телефона, email и адресов;
- цены оставлены как «уточняйте», чтобы не придумывать ваши реальные цены;
- используется официальное изображение WAKA soPro PA10000 с сайта WAKA.

## Важно
В открытых источниках ассортимент WAKA PA10000 различается по странам/рынкам. Поэтому вкусы в каталоге собраны из актуальных публичных списков, а не представлены как гарантированный ассортимент для любой страны.

Характеристики вроде «до 10 000 затяжек», 18 ml, 850 mAh и Dual Mesh встречаются в официальных/рыночных карточках PA10000, но отдельные конфигурации и крепость никотина могут различаться.

Перед публикацией:
1. замените контакты и адреса в `index.html`;
2. впишите ваши реальные цены;
3. при необходимости замените список вкусов в `script.js`;
4. проверьте требования к продаже и доставке никотиновой продукции в каждой стране, где сайт будет использоваться.

Для GitHub Pages достаточно загрузить `index.html`, `style.css`, `script.js` и папку `assets`.
